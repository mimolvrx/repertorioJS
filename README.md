# 📚 Repertório JS

Este projeto foi desenvolvido com fins educacionais e reúne diversas práticas de **JavaScript** focadas em manipulação do DOM e interatividade no front-end.

🔗 Acesse o projeto:
 [https://mimolvrx.github.io/repertorioJS/](https://mimolvrx.github.io/repertorioJS/)

---

## 🚀 Sobre o projeto

O **Repertório JS** é uma coleção de funcionalidades interativas criadas para praticar conceitos essenciais de desenvolvimento web.

O projeto simula comportamentos comuns encontrados em sites reais, permitindo explorar desde interações simples até manipulações mais dinâmicas com dados.

---

## 🛠️ Tecnologias utilizadas

* HTML5
* CSS3
* JavaScript

---

## ⚙️ Funcionalidades

O projeto inclui diversas implementações importantes para o desenvolvimento front-end:

* Manipulação do **DOM**
* Menu **hambúrguer responsivo**
* Mostrar e ocultar elementos na tela
* Troca dinâmica de textos
* Área em destaque com interação por clique
* **Modal** (janela sobreposta)
* Sistema de **abas (tabs)**
* **Carrossel** de conteúdo
* Requisição de dados + renderização na tela
* Botão de **voltar ao topo**

---

## 🎯 Objetivo

Este projeto foi criado com o objetivo de:

* Praticar conceitos fundamentais de JavaScript
* Aprender na prática a manipular elementos da página
* Simular funcionalidades reais de interfaces web
* Evoluir habilidades em front-end
